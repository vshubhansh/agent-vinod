A basic attempt to build a custom agent which could perform coding actions under the calculator directory of this project.

Model used:
```
gemini-2.5-flash
```

To use:

Create a .env file with the GEMINI_API_KEY
```
GEMINI_API_KEY=<your api key>
```

Create and activate the virtual env
```
uv venv
source .venv/bin/activate
```
